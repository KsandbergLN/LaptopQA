######################################################################
Dell Command | Integration Suite for System Center
Version 6.7.1
######################################################################

Release Date - April 2026

The Dell Command | Integration Suite for System Center is a
software deliverable that extends the System Center Configuration
Manager tool to provide management for Dell Business Client platforms,
and supports out of band features, and Dell Command | Warranty.

######################################################################
What’s New
######################################################################

- Improved the stability of the system.

######################################################################
Hardware and Software Requirements
######################################################################

- Dell Command | Integration Suite for System Center requires
  Microsoft .NET 4.8.0 to be installed on the target system.

- Operating systems supported:
    Windows Server 2016
    Windows Server 2019
    Windows Server 2022
	Windows Server 2025

- Supported Microsoft Endpoint Configuration Manager (MECM)
    Microsoft System Center 2403 Configuration Manager
	Microsoft System Center 2409 Configuration Manager
	Microsoft System Center 2503 Configuration Manager
	Microsoft System Center 2509 Configuration Manager

- Languages:
    English

- List of operating systems that are supported on the Managed Node:
    Windows 10
    Windows 11

######################################################################
INSTALLATION and UPGRADE - POINTS TO NOTE
######################################################################

- For more information about installation, see the
  Dell Command | Integration Suite for System Center User's Guide.

- The Configuration Manager extensions and the vPro application are
  supported only on systems that run the Configuration Manager Admin 
  Console.

######################################################################
Security and Permissions - POINTS TO NOTE
######################################################################

- The Configuration Manager extension requires you to Run as
  Administrator or run using an administrator’s operating system account. The
  Configuration Manager extensions also require the Full Administrator
  security role in Configuration Manager.

- The vPro application requires you to Run as Administrator or
  run using an administrator’s operating system account. The vPro application also
  requires full access to the Configuration Manager database.

######################################################################
ISSUES FIXED
######################################################################

- Application updates to address security vulnerabilities.

######################################################################
KNOWN ISSUES
######################################################################

- Uninstalling the application when it is running may not remove all
  the database files. The Configurations.sdf and Indications.sdf files
  can be manually removed from the %PROGRAMDATA% path.
